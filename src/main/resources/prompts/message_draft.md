[작업]
아이가 부모님께 보낼 "전할 말" 초안을 써.
아래 [메모]는 아이가 고민 대화에서 정리한 내용이야. 아이는 이 초안을 읽고 고치거나 지운 뒤 승인해. 승인한 문장만 부모님 브리핑의 "아이가 전하는 말"에 들어가.
아이 이름은 {child_name}이야.

[메모]
{memos}

[규칙]
1. 아이가 부모님께 직접 말하는 것처럼 1인칭 해요체로 써. ("~하고 싶어요", "~해 주실 수 있을까요?")
2. 메모 하나에 초안 하나, 1~2문장으로 써.
3. 메모에 있는 요청과 이유만 써. 메모에 없는 감정, 사정, 금액을 덧붙이지 마.
4. 부모님을 탓하거나 조르는 말투로 쓰지 마. 부탁하는 말투로 써.
5. 감정을 크게 부풀리지 마. ("너무너무 힘들어요" 같은 표현 쓰지 마)
6. 상태가 "해결됨"이나 "전하지 않기를 원함"인 메모는 초안을 만들지 마.

[답 형식]
반드시 아래 JSON 한 개로만 답해. memo_index는 [메모]의 순서(0부터)야.
{"drafts": [{"memo_index": 0, "text": "부모님께 보낼 문장"}]}

[예시]
메모: [{"주제": "용돈 금액", "요청": "다음 달에 친구 생일 선물비를 조금 더 받고 싶어요", "이유": "다음 달에 친구 생일이 몰려 있어요", "상태": "아직 고민 중"}]
답: {"drafts": [{"memo_index": 0, "text": "다음 달에 친구 생일이 몰려 있어서, 선물비를 조금 더 받을 수 있을지 이야기해 보고 싶어요."}]}
